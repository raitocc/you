# YOU 移动端高保真交互原型

最新交互：四个一级 Tab 页面共用固定 Logo/头像栏，详情页及发布页隐藏该栏，瞬间列表的搜索和标签在内容区域顶部固定。时光、同行恢复普通封面和独立导航，瞬间保留图片叠层导航。心情显示具体情绪；参与者使用头像。圈子包含多条多图演示帖子、点赞头像与评论，支持继续点赞和评论。发布页的标签、心情、同行、可见范围均使用自定义选择面板，可见范围支持多选；日期使用自定义日历。

底部 Tab 映射为：瞬间 `AiArtIcon`、时光 `AiBookIcon`、同行 `AiBackgroundIcon`、圈子 `AppleIntelligenceIcon`。默认态与激活态均使用官方 Outline，不改变轮廓；激活态以绿色强调。

直接用浏览器打开 `YOU-prototype.html`。这是内嵌 CSS 和 JavaScript 的单文件交付版，无需安装依赖。示例照片来自 Unsplash，需要联网加载。

开发源文件为 `index.html`、`style.css`、`app.js`。桌面展示手机画框，手机上自动铺满视口。

## 可体验流程

- 瞬间：Yours / Related、瀑布流、标签筛选、跨两类内容的关键词搜索、详情、同行与圈子来源跳转、组图左右拖拽、编辑、评论、同行及圈子分享。
- 发布：相册多选或文字入口，标题、正文、标签、心情、日期、地点、参与者、同行及多个圈子。
- 时光：时光集、时间线、叠放组图左右拖拽、设置封面、示例 AI 对话。
- 同行：创建、生成码、加入、状态管理、相册、成员动态、挂载瞬间。
- 圈子：头像切换、创建、邀请码加入、退出、动态、点赞及评论。

## 原型边界与规则

瞬间页分为 Yours（本人发布的全部记录）和 Related（本人所在同行与圈子中可访问的记录）；搜索覆盖两者并集并去重。本人已分享记录可同时出现在两类浏览列表。详情显示具体同行、圈子入口，他人内容无编辑或分享入口。圈子示例记录按所属圈子过滤，失去全部来源后不进入 Related 或搜索。

时光通过预设标签分组并随发布更新，本原型仍只用自己的瞬间组成时光；AI 文案和聊天为示例，没有连接 AI 服务。时光详情右上角支持分享到圈子：涉及用户集合必须是圈子成员集合的子集（相等也允许）。不满足条件的圈子禁用并列出缺少成员，提交时再次校验；已失效的分享不再显示在圈子中。演示成员：三两好友包含我、小满、阿远；我的家人包含我、妈妈、爸爸；周末徒步社包含我、小满、阿远、阿禾。新建圈子初始仅包含自己。

运行 `python build.py` 从源文件重新生成单文件交付版（内嵌头像），运行 `node verify-rules.cjs` 验证业务交互与集合边界。

同行体验码为 `YOU826`，圈子体验邀请码为 `YOU`。扫码以邀请码输入代替。没有真实用户、后端或权限服务。

瞬间、可见范围、时光分享目标保存到当前浏览器 localStorage；评论、点赞、新增同行与圈子、时光封面只在当前页面会话生效。图片上传为浏览器本地读取，不上传服务器。浏览器存储有容量限制。成员数据与权限校验均为前端演示，无真实权限服务。

设计参考用户提供的 Instagram 截图，使用 UI UX Pro Max 的极简样式建议：黑白主体、充足留白、圆形圈子入口、图片优先、悬浮胶囊底栏和轻量暖绿色点缀。

图标统一采用 [Hugeicons Free · Stroke Rounded](https://github.com/hugeicons/hugeicons-static)，SVG 存放于 `assets/hugeicons` 并内嵌进单文件原型。中文使用 `PingFang SC`，英文使用 `SF Pro`（兼容 `SF Pro Text` / `SF Pro Display`）；调用设备本地字体，缺少对应字体时回退到系统字体。未分发 Apple 字体文件。

本轮更新：瞬间图片保留原比例并全幅展示，组图支持触屏滑动、鼠标拖拽、键盘方向键，带页码及圆点。封面采用叠层导航与渐变淡出。心情使用情绪配色和 Hugeicons 表情图标；圈子选中头像右上角可打开详情、更换头像、查看成员（成员为演示数据）。

最新详情样式：瞬间详情顶部不显示“瞬间”文本；时光与同行详情使用叠层导航与封面渐变淡出，一级 Logo 栏在详情中隐藏。当前用户头像使用用户提供的 Calmer.png，并内嵌于单文件 HTML 中。
