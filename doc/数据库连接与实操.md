# 连接 MySQL，完成 test 表的增删改查

本次操作围绕已经建好的 `test` 表展开：先验证 Java 能连接 MySQL，再通过 MyBatis-Plus 新增、查询、修改和删除一条记录。

示例沿用当前项目的启动包 `com.you.youbackend`。Compose 配置的数据库名为 `you`，账号和密码均为 `you`，本机端口为 `3306`。本文以 `you` 库中的 `test` 表为目标。

## 1. 确认表所在的数据库

在建表时使用的数据库工具中执行：

```sql
SELECT DATABASE();
SHOW COLUMNS FROM test;
```

第一条查询显示当前库名，第二条确认表字段：

| 字段 | MySQL 类型 | 规则 |
|---|---|---|
| id | INT | 自增主键 |
| name | VARCHAR(10) | 必填，最多 10 个字符 |

后面的连接地址使用库名 `you`。如果第一条查询显示其他库名，将连接地址最后的 `you` 换成该库名，并使用有权访问它的账号。

## 2. 添加数据库依赖

在 `you-backend/pom.xml` 的 `<dependencies>` 中追加：

```xml
<dependency>
    <groupId>com.baomidou</groupId>
    <artifactId>mybatis-plus-spring-boot4-starter</artifactId>
    <version>3.5.18</version>
</dependency>

<dependency>
    <groupId>com.mysql</groupId>
    <artifactId>mysql-connector-j</artifactId>
    <scope>runtime</scope>
</dependency>
```

重新加载 Maven。MyBatis-Plus starter 提供数据库访问集成，MySQL 驱动负责建立连接。当前项目已有 Lombok 和测试依赖，后续示例直接使用它们。[MyBatis-Plus 接入说明](https://baomidou.com/getting-started/install/)

## 3. 配置连接地址

将 `you-backend/src/main/resources/application.yaml` 中的 `spring:` 配置整理为：

```yaml
spring:
  application:
    name: you-backend
  datasource:
    url: jdbc:mysql://localhost:3306/you
    username: you
    password: you
```

连接地址中的 `localhost` 是本机，`3306` 是 MySQL 映射端口，末尾的 `you` 是数据库名。`test` 是稍后由实体映射的表名。

启动 Docker Desktop，在 YOU 根目录执行：

```powershell
docker compose up -d mysql
```

Spring Boot 会使用这组配置创建数据源，驱动类由 JDBC 地址识别。[数据源配置说明](https://docs.spring.io/spring-boot/reference/data/sql.html)

## 4. 定义 test 表的实体和 Mapper

### 4.1 用 Java 对象表示一条记录

创建 `you-backend/src/main/java/com/you/youbackend/dbtest/TestRecord.java`：

```java
package com.you.youbackend.dbtest;

import com.baomidou.mybatisplus.annotation.IdType;
import com.baomidou.mybatisplus.annotation.TableId;
import com.baomidou.mybatisplus.annotation.TableName;
import lombok.Data;

@Data
@TableName("test")
public class TestRecord {
    @TableId(type = IdType.AUTO)
    private Integer id;
    private String name;
}
```

`@TableName("test")` 指定表名，`IdType.AUTO` 对应数据库自增，`Integer` 对应 SQL 中的 INT。`@Data` 提供 getter、setter，方便读取和设置属性。

### 4.2 创建数据库访问接口

在同一目录创建 `TestRecordMapper.java`：

```java
package com.you.youbackend.dbtest;

import com.baomidou.mybatisplus.core.mapper.BaseMapper;
import org.apache.ibatis.annotations.Mapper;

@Mapper
public interface TestRecordMapper extends BaseMapper<TestRecord> {
}
```

继承 `BaseMapper<TestRecord>` 后，可以直接调用 `insert`、`selectById`、`updateById`、`deleteById`。`@Mapper` 让 Spring 创建这个接口的数据库访问对象。

## 5. 先运行连接测试，再运行增删改查

创建 `you-backend/src/test/java/com/you/youbackend/dbtest/TestRecordMapperTest.java`：

```java
package com.you.youbackend.dbtest;

import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.context.SpringBootTest;
import org.springframework.transaction.annotation.Transactional;

import javax.sql.DataSource;
import java.sql.Connection;
import java.sql.PreparedStatement;
import java.sql.ResultSet;
import java.sql.SQLException;

import static org.junit.jupiter.api.Assertions.*;

@SpringBootTest
class TestRecordMapperTest {

    @Autowired
    private DataSource dataSource;

    @Autowired
    private TestRecordMapper testRecordMapper;

    @Test
    void connect() throws SQLException {
        try (Connection connection = dataSource.getConnection();
             PreparedStatement statement = connection.prepareStatement("SELECT 1");
             ResultSet result = statement.executeQuery()) {
            assertTrue(result.next());
            assertEquals(1, result.getInt(1));
            System.out.println("当前数据库：" + connection.getCatalog());
        }
    }

    @Test
    @Transactional
    void crud() {
        // 1. 新增
        TestRecord record = new TestRecord();
        record.setName("小明");
        assertEquals(1, testRecordMapper.insert(record));

        Integer id = record.getId();
        assertNotNull(id);
        System.out.println("新增成功，id=" + id);

        // 2. 查询
        TestRecord loaded = testRecordMapper.selectById(id);
        assertNotNull(loaded);
        assertEquals("小明", loaded.getName());
        System.out.println("查询结果：" + loaded);

        // 3. 修改
        TestRecord patch = new TestRecord();
        patch.setId(id);
        patch.setName("小红");
        assertEquals(1, testRecordMapper.updateById(patch));

        TestRecord updated = testRecordMapper.selectById(id);
        assertNotNull(updated);
        assertEquals("小红", updated.getName());
        System.out.println("修改结果：" + updated);

        // 4. 删除刚新增的记录
        assertEquals(1, testRecordMapper.deleteById(id));
        assertNull(testRecordMapper.selectById(id));
        System.out.println("删除成功");
    }
}
```

### 5.1 运行 connect

点击 `connect()` 方法旁边的运行按钮。预期测试通过，控制台输出：

```text
当前数据库：you
```

这表示应用的数据源已经连到 MySQL，并成功执行了 `SELECT 1`。

### 5.2 运行 crud

接着运行 `crud()`。预期四次操作均通过，控制台依次显示新增、查询、修改、删除结果。

`insert` 成功后，自增 ID 回填到 `record.id`；接下来的操作都使用这个实际 ID。`@Transactional` 使测试结束后回滚本次数据变更。

这两个测试分别确认“连接可用”和“表映射及读写可用”。完成后，就可以将同样的 Mapper 调用放入业务 Service 中。

## 6. 查看表中已有的记录

需要读取现有数据时，在测试类中增加下面的方法，并导入这两个类型：

```java
import com.baomidou.mybatisplus.core.toolkit.Wrappers;
import java.util.List;
```

```java
@Test
void listRecords() {
    List<TestRecord> records = testRecordMapper.selectList(
            Wrappers.<TestRecord>lambdaQuery()
                    .select(TestRecord::getId, TestRecord::getName)
                    .orderByAsc(TestRecord::getId)
    );
    records.forEach(System.out::println);
}
```

运行后按 ID 顺序打印现有记录。数据库工具中也可以用以下 SQL 查看相同内容：

```sql
SELECT id, name FROM test ORDER BY id;
```

## 7. 按错误定位问题

| 现象 | 检查与处理 |
|---|---|
| 数据库连接失败 | 确认 MySQL 容器运行，核对本机端口 3306 |
| `Access denied` | 核对账号、密码及目标库的访问权限 |
| `Unknown database` | 用第 1 节查询确认库名，再调整 JDBC 地址 |
| `Table ... test doesn't exist` | 确认 `test` 表位于当前连接的数据库中 |
| Mapper Bean 创建失败 | 确认 `@Mapper` 已添加，包名为启动包的子包 |
| getter、setter 报错 | 确认 Lombok 注解处理生效 |
| 姓名写入报长度错误 | 姓名长度按表定义控制在 10 个字符以内 |

本次直接使用已建好的表验证数据读写；后续表结构升级可沿用 Flyway 教程中的迁移流程。
