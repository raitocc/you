# YOU 数据库设计

## 设计概述

YOU 是用户记录、整理和分享个人经历的平台。本设计以“瞬间”为基本内容单位，围绕时光、同行和圈子组织这些记录，并提供用户信箱和站内通知。当前共 14 张表，覆盖下述基础业务范围。

- **瞬间**：用户发布的文字、图片或图文记录，原内容保存一份。
- **时光**：由用户手动选择或 AI 一次性整理形成的瞬间集合。
- **同行**：围绕一次共同经历组织成员和瞬间。
- **圈子**：由一群人组成的持续分享空间，可分享瞬间、时光和同行入口。
- **用户信箱**：接收相关空间的新内容动态。
- **站内通知**：接收与用户有关的互动或业务结果提示。

本版先支持基础账号、图片记录、一次性 AI 整理、成员与内容分享、站内消息。草稿保存在客户端本地；时光不自动持续维护；空间由创建者管理。点赞、评论尚未设计实际业务表，目前仅在通知类型中预留，因此不计入本版已覆盖的业务。本文用于说明表结构及主要业务关系，不表示相关功能已经实现。

## 通用约定

1. **标识**：各表主键使用 UUIDv7，数据库存储为 `BINARY(16)`；引用这些对象的 ID 使用相同类型。接口使用 UUID 字符串，应用统一完成转换。
2. **审计时间**：`created_at`、`updated_at` 为非空的 `DATETIME(3)`，由应用统一填充，按 UTC 写入和读取，界面按用户所需时区展示。`memory_time` 是经历发生时间，不用主键生成时间或发布时间代替。
3. **逻辑删除**：`deleted_at` 可空，为空表示未删除；空间中表示解散，成员关系中表示离开或移除，分享关系中表示撤回。默认业务读取忽略已删除对象或无效关系。文件是否物理回收，还要确认没有其他有效引用。
4. **唯一关系**：已注明联合唯一的成员、集合及分享关系不重复建立。重新建立时恢复原行；恢复分享同时更新本次分享时间。联合唯一键本身不加入可空的 `deleted_at`。
5. **引用原内容**：加入时光、关联同行、分享到圈子均不复制瞬间。移出集合或撤销分享只改变关系；删除原瞬间后，各入口停止展示该内容。
6. **类型与 ID**：多态引用使用明确的类型及对象 ID，例如 `circle_share.object_type` 与 `object_id`；服务层按类型定位原表，并校验对应操作资格。普通 ID 引用本身不是查看凭证。
7. **已读**：`read_at` 为空表示未读，有值表示已读；读消息不改变成员、分享或原对象的业务状态。
8. **关联维护**：应用层通过业务校验与事务维护表间关联；数据库使用主键、唯一索引和非空约束表达基本数据规则。
9. **字符比较**：默认使用 MySQL 8.4 的 `utf8mb4_0900_ai_ci` 排序规则，登录账号比较忽略大小写；`media_file.storage_key` 单独使用 `utf8mb4_0900_bin`，按对象键精确匹配。
10. **初始迁移**：表结构文件位于 `you-backend/src/main/resources/db/migration/V1.0__init_schema.sql`，迁移版本采用 `1.0`、`1.1` 等递增编号。

## 浏览与共享规则

- **Yours**：查询本人发布且未删除的瞬间。
- **Related**：查询有效同行中的瞬间，以及有效圈子直接分享的瞬间；按瞬间 ID 去重，并保留当前有效来源。本人已经分享的瞬间可以同时出现在 Yours 和 Related。
- **搜索**：在上述两类可访问瞬间的并集中查找，不受当前浏览 Tab 限制。当前字段支持普通条件查询；自然语言理解和语义检索由相应服务及检索索引实现。
- **集合入口**：分享到圈子的时光仍按原瞬间权限展示内容；分享到圈子的同行，非同行成员只进入介绍及加入入口，确认加入后才建立同行资格。
- **内容与消息**：成员及分享关系决定当前访问范围；信箱、通知只是入口。新发布到同行或新分享到圈子可生成信箱动态，已有内容编辑不重复刷出新动态。成员变化、空间解散和 AI 完成等生成对应站内通知。

## 用户表（app_user）

保存用户的登录账号、密码散列和个人资料，是瞬间作者、时光所有者、空间创建者及成员身份的统一来源。昵称可以重名，登录账号唯一。头像通过 `avatar_file_id` 引用媒体文件；本版账号模块只使用这一张表。

| 字段 | 含义 | 类型 |
|---|---|---|
| id | 用户 ID，主键，使用 UUIDv7 | BINARY(16) |
| username | 登录账号，非空、唯一 | VARCHAR(64) |
| password_hash | 密码散列，非空 | VARCHAR(255) |
| nickname | 展示昵称，可空，允许重名 | VARCHAR(64) |
| avatar_file_id | 头像文件 ID，可空，关联 media_file.id | BINARY(16) |
| created_at | 创建时间，UTC | DATETIME(3) |
| updated_at | 最后修改时间，UTC | DATETIME(3) |
| deleted_at | 删除时间，UTC；为空表示未删除 | DATETIME(3) |

## 媒体文件表（media_file）

保存头像、瞬间组图和时光封面使用的图片元数据，文件内容存放在私有 RustFS 对象存储中。本版采用上传并检查成功后建立文件记录的方式，因此不单独维护上传任务状态。`storage_key` 用于定位文件，访问时根据实际引用和当前用户权限生成临时地址；临时地址不写入本表。文件有其他有效用途时，不因某一处引用移除而直接清理文件。

| 字段 | 含义 | 类型 |
|---|---|---|
| id | 文件 ID，主键，使用 UUIDv7 | BINARY(16) |
| owner_user_id | 上传者 ID，非空，关联 app_user.id | BINARY(16) |
| storage_key | RustFS 对象键，非空、唯一 | VARCHAR(512) |
| mime_type | 实际文件类型，例如 image/jpeg，非空 | VARCHAR(64) |
| byte_size | 文件字节数，非空、正整数 | BIGINT |
| created_at | 创建时间，UTC | DATETIME(3) |
| updated_at | 最后修改时间，UTC | DATETIME(3) |
| deleted_at | 删除时间，UTC；为空表示未删除 | DATETIME(3) |

## 瞬间表（moment）

保存一条生活记录的原始内容，一条瞬间只有一个作者。标题可选，正文和图片至少有一种；图片和标签分别存放在对应关联表。`memory_time` 表示经历发生的时间，与发布时的 `created_at` 分开。可空的 `gathering_id` 表示当前关联同行，从结构上限制一条瞬间最多属于一个同行；分享到多个圈子则通过 `circle_share` 表达。各入口读取同一份瞬间，不复制原始图文。

| 字段 | 含义 | 类型 |
|---|---|---|
| id | 瞬间 ID，主键，使用 UUIDv7 | BINARY(16) |
| created_at | 创建时间，即发布时间，UTC | DATETIME(3) |
| updated_at | 最后修改时间，UTC | DATETIME(3) |
| author_user_id | 作者 ID，非空，关联 app_user.id | BINARY(16) |
| gathering_id | 当前关联的同行 ID，可空，关联 gathering.id | BINARY(16) |
| title | 标题，可空 | VARCHAR(255) |
| body | 普通文本正文，可空；去除空白后非空或至少有一张图片 | TEXT |
| mood | 心情，可空 | VARCHAR(64) |
| memory_time | 瞬间发生时间，非空，UTC | DATETIME(3) |
| latitude | 纬度，可空，范围 -90 至 90，与经度同时为空或同时有值 | DECIMAL(10,7) |
| longitude | 经度，可空，范围 -180 至 180，与纬度同时为空或同时有值 | DECIMAL(10,7) |
| location_name | 地点名称，可空 | VARCHAR(255) |
| location_address | 地点地址，可空 | VARCHAR(512) |
| deleted_at | 删除时间，UTC；为空表示未删除 | DATETIME(3) |

## 瞬间图片表（moment_image）

记录瞬间使用了哪些媒体文件，以及组图展示顺序。一个瞬间可以包含多张图片，每条记录引用一个 `media_file`。同一瞬间的同一个文件只保留一条关系，移除后再次添加时恢复原行；应用层在一次事务中维护有效图片的顺序。调整图片顺序或移除图片只改变瞬间与文件的关系，不直接删除被其他有效用途引用的文件。

| 字段 | 含义 | 类型 |
|---|---|---|
| id | 图片关联 ID，主键，使用 UUIDv7 | BINARY(16) |
| moment_id | 瞬间 ID，非空，关联 moment.id，与 file_id 联合唯一 | BINARY(16) |
| file_id | 图片文件 ID，非空，关联 media_file.id | BINARY(16) |
| sort_order | 图片展示顺序，非空，从 1 开始，同一瞬间内有效图片的顺序由应用维护且不重复 | INT |
| created_at | 创建时间，UTC | DATETIME(3) |
| updated_at | 最后修改时间，UTC | DATETIME(3) |
| deleted_at | 删除时间，UTC；为空表示未删除 | DATETIME(3) |

## 瞬间标签表（moment_tag）

直接保存瞬间的标签名称，一条瞬间可以有多条标签记录，同一瞬间内标签名称不重复。本版不建立独立标签字典；按标签查询时从本表定位对应瞬间。删除某条标签记录只影响该瞬间，不会修改其他瞬间中的同名标签。

| 字段 | 含义 | 类型 |
|---|---|---|
| id | 标签记录 ID，主键，使用 UUIDv7 | BINARY(16) |
| moment_id | 瞬间 ID，非空，关联 moment.id | BINARY(16) |
| tag_name | 标签名称，非空、非空白，同一瞬间内不可重复 | VARCHAR(64) |
| created_at | 创建时间，UTC | DATETIME(3) |
| updated_at | 最后修改时间，UTC | DATETIME(3) |
| deleted_at | 删除时间，UTC；为空表示未删除 | DATETIME(3) |

## 时光表（album）

保存用户建立的瞬间集合及其名称、介绍和封面。`manual` 表示手动选择瞬间创建，`ai` 表示由 AI 按指定要求整理；`organize_prompt` 记录该次整理要求，不作为持续执行的规则。AI 每次只整理确认的范围，例如一月份的记录；后续新增瞬间不自动加入，用户可以手动调整集合，或再次执行整理。删除时光保留其中的原始瞬间。

| 字段 | 含义 | 类型 |
|---|---|---|
| id | 时光 ID，主键，使用 UUIDv7 | BINARY(16) |
| created_at | 创建时间，UTC | DATETIME(3) |
| updated_at | 最后修改时间，UTC | DATETIME(3) |
| owner_user_id | 所有者 ID，非空，关联 app_user.id | BINARY(16) |
| name | 时光名称，非空、非空白，允许重名 | VARCHAR(128) |
| description | 时光介绍，可空 | TEXT |
| organize_mode | 整理方式，非空，默认 manual；manual 手动、ai AI 整理 | VARCHAR(16) |
| organize_prompt | AI 整理要求，可空，例如“整理一月份的旅行瞬间” | TEXT |
| cover_file_id | 封面文件 ID，可空，关联 media_file.id | BINARY(16) |
| deleted_at | 删除时间，UTC；为空表示未删除 | DATETIME(3) |

## 时光瞬间关联表（album_moment）

记录一个时光包含哪些瞬间。时光与瞬间是多对多关系：一个时光可包含多条瞬间，同一瞬间也可属于多个时光。同一对时光和瞬间仅保留一条关系；移出后再次加入时恢复原关系。时光线按原瞬间发生时间及 ID 排列，不在本表重复保存图文、时间或人工排序字段。

| 字段 | 含义 | 类型 |
|---|---|---|
| id | 关联 ID，主键，使用 UUIDv7 | BINARY(16) |
| created_at | 创建时间，UTC | DATETIME(3) |
| updated_at | 最后修改时间，UTC | DATETIME(3) |
| album_id | 时光 ID，非空，关联 album.id，与 moment_id 联合唯一 | BINARY(16) |
| moment_id | 瞬间 ID，非空，关联 moment.id | BINARY(16) |
| deleted_at | 移出时间，UTC；为空表示关联有效 | DATETIME(3) |

## 同行表（gathering）

保存围绕一次共同经历建立的记录空间。创建者负责编辑信息、结束和解散等管理操作，本版不设置独立管理员，也不支持管理权转交。进行中和已结束均允许加入与补记，解散通过 `deleted_at` 表达。`invite_code` 是长期加入凭证，二维码是该凭证的展示方式；关闭邀请或重置旧码后，旧入口不能继续用于加入，已加入成员不受影响。同行中的瞬间通过 `moment.gathering_id` 查询。

| 字段 | 含义 | 类型 |
|---|---|---|
| id | 同行 ID，主键，使用 UUIDv7 | BINARY(16) |
| created_at | 创建时间，UTC | DATETIME(3) |
| updated_at | 最后修改时间，UTC | DATETIME(3) |
| creator_user_id | 创建者 ID，非空，关联 app_user.id；创建者负责同行管理操作 | BINARY(16) |
| name | 同行名称，非空、非空白，允许重名 | VARCHAR(128) |
| description | 同行介绍，可空 | TEXT |
| status | 同行状态，非空，默认 1；1 进行中、2 已结束 | TINYINT |
| invite_enabled | 是否允许通过同行码加入，非空，0 否、1 是，默认 1 | TINYINT |
| invite_code | 同行邀请码，非空、唯一，由系统随机生成，可重置 | VARCHAR(16) |
| deleted_at | 解散时间，UTC；为空表示未解散 | DATETIME(3) |

## 同行成员表（gathering_member）

保存用户与同行的成员关系，创建同行时同时建立创建者的成员关系。同一用户在同一同行只保留一条记录，退出或移除通过 `deleted_at` 标记，再次加入恢复原关系。退出或被移除时，取消该用户瞬间与当前同行的关联，保留原瞬间；创建者暂不直接退出自己创建的同行，可选择解散。从圈子中选择成员创建同行时，直接建立所选成员的关系，不经过定向邀请确认；加入同行不会自动关联成员原有的瞬间。

| 字段 | 含义 | 类型 |
|---|---|---|
| id | 成员关系 ID，主键，使用 UUIDv7 | BINARY(16) |
| created_at | 创建时间，UTC | DATETIME(3) |
| updated_at | 最后修改时间，UTC | DATETIME(3) |
| gathering_id | 同行 ID，非空，关联 gathering.id，与 user_id 联合唯一 | BINARY(16) |
| user_id | 成员 ID，非空，关联 app_user.id | BINARY(16) |
| deleted_at | 离开或被移除的时间，UTC；为空表示成员关系有效 | DATETIME(3) |

## 圈子表（circle）

保存围绕一群人建立的持续分享空间。创建者负责圈子管理，本版不设置独立管理员；成员资格通过 `circle_member` 维护，内容通过 `circle_share` 维护。圈子邀请码和邀请开关用于控制加入入口。圈子没有进行中、已结束的阶段区别，解散只记录 `deleted_at`，保留原瞬间、时光及独立同行。

| 字段 | 含义 | 类型 |
|---|---|---|
| id | 圈子 ID，主键，使用 UUIDv7 | BINARY(16) |
| created_at | 创建时间，UTC | DATETIME(3) |
| updated_at | 最后修改时间，UTC | DATETIME(3) |
| creator_user_id | 创建者 ID，非空，关联 app_user.id；创建者负责圈子管理操作 | BINARY(16) |
| name | 圈子名称，非空、非空白，允许重名 | VARCHAR(128) |
| description | 圈子介绍，可空 | TEXT |
| invite_enabled | 是否允许通过圈子码加入，非空，0 否、1 是，默认 1 | TINYINT |
| invite_code | 圈子邀请码，非空、唯一，由系统随机生成，可重置 | VARCHAR(16) |
| deleted_at | 解散时间，UTC；为空表示未解散 | DATETIME(3) |

## 圈子成员表（circle_member）

保存用户与圈子的成员关系，创建圈子时同时建立创建者的成员关系。同一用户在同一圈子只保留一条记录，离开或被移除时标记 `deleted_at`，再次加入恢复原关系，但不自动恢复旧分享。退出或移除时撤回该用户在圈子中的分享；创建者暂不直接退出自己创建的圈子，可选择解散。

| 字段 | 含义 | 类型 |
|---|---|---|
| id | 成员关系 ID，主键，使用 UUIDv7 | BINARY(16) |
| created_at | 创建时间，UTC | DATETIME(3) |
| updated_at | 最后修改时间，UTC | DATETIME(3) |
| circle_id | 圈子 ID，非空，关联 circle.id，与 user_id 联合唯一 | BINARY(16) |
| user_id | 成员 ID，非空，关联 app_user.id | BINARY(16) |
| deleted_at | 离开或被移除的时间，UTC；为空表示成员关系有效 | DATETIME(3) |

## 圈子分享表（circle_share）

统一记录瞬间、时光和同行在圈子中的分享入口，使用 `object_type` 与 `object_id` 定位原对象，不复制原内容。`sharer_user_id` 表示本次分享者，`shared_at` 用于排序；编辑原对象不改变分享时间。同一圈子内同一种对象只保留一条关系，撤回后重新分享恢复原行并更新分享者和分享时间。时光分享不自动授予内部瞬间权限；同行分享也不自动建立同行成员关系。

| 字段 | 含义 | 类型 |
|---|---|---|
| id | 分享关系 ID，主键，使用 UUIDv7 | BINARY(16) |
| created_at | 创建时间，UTC | DATETIME(3) |
| updated_at | 最后修改时间，UTC | DATETIME(3) |
| circle_id | 目标圈子 ID，非空，关联 circle.id；与 object_type、object_id 联合唯一 | BINARY(16) |
| object_type | 分享对象类型，非空，moment 瞬间、album 时光、gathering 同行 | VARCHAR(16) |
| object_id | 原对象 ID，非空，与对象类型对应 | BINARY(16) |
| sharer_user_id | 本次分享者 ID，非空，关联 app_user.id | BINARY(16) |
| shared_at | 本次分享时间，UTC，用于圈子内容排序；重新分享时更新，编辑原对象不改变 | DATETIME(3) |
| deleted_at | 撤回或移除时间，UTC；为空表示分享关系未撤销 | DATETIME(3) |

## 用户信箱表（user_inbox）

保存相关同行、圈子中的新内容动态，例如同行新增瞬间、圈子分享时光。每条记录属于一个接收者，`source_type` 与 `source_id` 表示来源空间，`object_type` 与 `object_id` 表示打开的内容，两者可以分别导航。本表只保存动态入口，不复制图文，也不代替成员或分享关系。`read_at` 记录用户是否读过；查看动态及打开内容时仍按当前空间和原对象权限判断。

| 字段 | 含义 | 类型 |
|---|---|---|
| id | 信箱动态 ID，主键，使用 UUIDv7 | BINARY(16) |
| created_at | 创建时间，UTC | DATETIME(3) |
| updated_at | 最后修改时间，UTC | DATETIME(3) |
| recipient_user_id | 接收者 ID，非空，关联 app_user.id | BINARY(16) |
| actor_user_id | 发布或分享内容的用户 ID，非空，关联 app_user.id | BINARY(16) |
| source_type | 来源空间类型，非空，gathering 同行、circle 圈子 | VARCHAR(16) |
| source_id | 来源同行或圈子的 ID，非空 | BINARY(16) |
| object_type | 内容类型，非空，moment 瞬间、album 时光、gathering 同行 | VARCHAR(16) |
| object_id | 对应内容 ID，非空 | BINARY(16) |
| read_at | 已读时间，UTC；为空表示未读 | DATETIME(3) |
| deleted_at | 删除时间，UTC；为空表示未删除 | DATETIME(3) |

## 站内通知表（notification）

保存与用户有关的互动或业务结果，例如被加入同行、被移除、空间解散或 AI 整理完成。用户触发的通知记录触发者，系统通知允许触发者为空；无具体目标时，目标类型和 ID 同时为空。`content` 保存简短通知文案，`read_at` 表示是否已读。点赞和评论类型仅为通知表达预留，不代表本版已具备点赞、评论业务存储。来源失效时可保留必要结果提示，打开关联内容仍检查当前权限。

| 字段 | 含义 | 类型 |
|---|---|---|
| id | 通知 ID，主键，使用 UUIDv7 | BINARY(16) |
| created_at | 创建时间，UTC | DATETIME(3) |
| updated_at | 最后修改时间，UTC | DATETIME(3) |
| recipient_user_id | 接收者 ID，非空，关联 app_user.id | BINARY(16) |
| actor_user_id | 触发通知的用户 ID，关联 app_user.id；系统通知可空 | BINARY(16) |
| notification_type | 通知类型，非空，例如 like、comment、member_added、removed、dissolved、ai_completed | VARCHAR(32) |
| target_type | 关联对象类型，moment、album、gathering、circle；无关联对象时可空 | VARCHAR(16) |
| target_id | 关联对象 ID，可空，与 target_type 同时为空或同时有值 | BINARY(16) |
| content | 简短通知文案，非空 | VARCHAR(255) |
| read_at | 已读时间，UTC；为空表示未读 | DATETIME(3) |
| deleted_at | 删除时间，UTC；为空表示未删除 | DATETIME(3) |
