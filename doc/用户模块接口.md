## 接口规范

### 基础配置

```
Base URL: http://localhost:8080
API Version: v1
API Prefix: /
```

版本为契约版本，不加入 URL；部署环境使用 HTTPS，替换 Base URL，保留相对路径。

约定不同业务模块前缀：

- 用户：`user`
- 瞬间：`moment`
- 时光：`album`
- 同行：`gathering`
- 圈子：`circle`
- 消息：`message`
- AI：`ai`

### 接口风格

采用 RESTful 风格，使用名词表示资源，示例：

| 操作 | HTTP Method | URL 示例 |
| --- | --- | --- |
| 创建用户 | POST | `/user/users` |
| 创建登录会话 | POST | `/user/sessions` |
| 查询当前用户 | GET | `/user/users/me` |
| 部分更新瞬间 | PATCH | `/moment/moments/{momentId}` |
| 替换可见范围 | PUT | `/moment/moments/{momentId}/visibility` |
| 删除瞬间 | DELETE | `/moment/moments/{momentId}` |

### 数据格式

- JSON 使用 UTF-8、camelCase，`Content-Type: application/json`。
- 文件上传使用 `multipart/form-data`，媒体内容以二进制返回。
- JSON 写入请求体最大 **1 MiB**；图片大小限制由上传接口定义。
- 参数位置明确标注 `Header`、`Path`、`Query`，其余默认为 `Body`。

### 响应与错误处理

- 成功响应：`{code: "SUCCESS", message, data}`；创建用户、瞬间、文件返回 **201**，其他成功返回 **200**。
- 错误响应：`{code, message, data: null}`；可附 `errors: [{field, reason, targetId}]`，无目标时 `targetId=null`。
- 错误响应不得暴露堆栈、数据库等内部信息。

### 时间规范

- 响应时间统一为 **UTC 毫秒精度**，格式：`2026-11-03T02:00:00.000Z`。
- 输入时间必须包含时区，服务端统一转换为 UTC。
- 时间区间采用 **左闭右开** `**[start, end)**`。
- 记忆时间未传时默认为当前时刻；客户端按用户时区展示及选择日期。

### 认证与授权

使用 JWT Bearer Token，示例：

```
GET /user/users/me
Authorization: Bearer eyJhbGciOi...
```

- 注册、登录公开；其他接口需要 JWT。
- 令牌固定有效期 7 天（604800 秒），无刷新接口，到期重新登录。
- 验证签名、有效期、签发者和受众；服务端仅接受固定配置的签名算法。

## POST 用户注册

POST /user/users

POST `/user/users` 公开接口

创建用户名密码账号，注册成功后由客户端进入登录。

#### 基本信息

| 属性 | 内容 |
| --- | --- |
| 接口名称 | 用户注册 |
| 请求方式 | POST |
| 请求路径 | `/user/users` |
| 认证要求 | 不需要 |
| 成功状态码 | 201 |

#### 请求参数

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| username | string | 是 | 4～64 位 ASCII 字母、数字、下划线；首位字母；统一转小写后唯一 |
| password | string | 是 | 8～64 字符，至少包含字母与数字，不截断、不去空白 |
| nickname | string | 是 | 去首尾空白后 1～64 字符，允许重名 |

#### 请求示例

```json
{
  "username": "calmer",
  "password": "Example12345",
  "nickname": "小满"
}
```

#### 响应数据

以下字段均位于成功响应的 data 内。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 用户 UUIDv7 |
| username | string | 本人登录账号，仅本人接口返回 |
| nickname | string | 昵称 |
| avatarFileId | string / null | 头像文件 ID |
| avatarContentPath | string / null | 受保护的头像读取路径，未设置为 null |
| createdAt | string | 注册时间 |
| updatedAt | string | 资料最后更新时间 |

#### 响应示例

```json
{
  "code": "SUCCESS",
  "message": "操作成功",
  "data": {
    "id": "019a48d0-0000-7000-8000-000000000001",
    "username": "calmer",
    "nickname": "小满",
    "avatarFileId": null,
    "avatarContentPath": null,
    "createdAt": "2026-11-03T02:00:00.000Z",
    "updatedAt": "2026-11-03T02:00:00.000Z"
  }
}
```

#### 业务规则

- 对 username 进行统一规范化，唯一索引冲突映射为 ACCOUNT_UNAVAILABLE；软删除账号仍占用原 username，不自动复用。
- 仅存自适应加盐密码散列，不返回散列、明文密码，不将密码写入日志；注册无邮箱或手机验证。
- 注册不自动签发令牌。结果未知先尝试登录同一账号；用户名被占用不等于原注册成功。重复注册不覆盖密码或资料。
- 初始头像为空，昵称不作为登录标识。

#### 异常处理

| HTTP 状态码 | 业务错误码 | 场景 |
| --- | --- | --- |
| 409 | ACCOUNT_UNAVAILABLE | 账号不可用，调整账号或尝试登录 |
| 400 | INVALID_PARAMETER | 账号、密码或昵称不符合要求 |

## GET 访问用户头像

GET /user/users/{userId}/avatar

GET `/user/users/{userId}/avatar` · JWT Bearer Token

用户模块按 userId 查询当前头像。本人可以访问自己的当前头像；其他用户须具有展示该用户资料的业务关系，例如可访问瞬间的作者、有效同行或圈子的共同成员。服务端校验用户、当前头像引用及文件有效性。

#### 访问图片

业务鉴权成功后，内部调用共用的存储组件签发 5 分钟有效的 GET 地址，以 HTTP 302 返回 Location。响应头 Cache-Control 为 private, no-store。客户端跟随重定向取得图片二进制；签名地址采用对象存储鉴权，应用 Bearer Token 用于访问本业务入口。

```http
HTTP/1.1 302 Found
Location: https://storage.example.com/you-files/images/example.jpg?X-Amz-Signature=example
Cache-Control: private, no-store
```

每次访问业务入口均重新鉴权；已签发地址在到期前仍可使用，权限变更后最多存在 5 分钟的旧地址有效期。到期后重新访问业务入口获取新地址。文件上传接口统一位于 media 模块，访问资格由本业务模块负责。

异常使用 JSON ErrorResponse：401 登录状态无效；404 对象或图片不存在、已删除或当前无访问资格；503 对象存储暂时不可用。

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|userId|path|string(uuid)| 是 |头像所属用户 UUID|

> 返回示例

> 401 Response

```json
{
  "code": "string",
  "message": "string",
  "data": null,
  "errors": [
    {
      "field": "string",
      "reason": "string",
      "targetId": "string"
    }
  ]
}
```

### 返回结果

|状态码|状态码含义|说明|数据模型|
|---|---|---|---|
|302|[Found](https://tools.ietf.org/html/rfc7231#section-6.4.3)|通过业务鉴权后返回 Location，客户端跟随重定向获取 RustFS 图片|None|
|401|[Unauthorized](https://tools.ietf.org/html/rfc7235#section-3.1)|UNAUTHORIZED：登录状态无效|[ErrorResponse](#schemaerrorresponse)|
|404|[Not Found](https://tools.ietf.org/html/rfc7231#section-6.5.4)|RESOURCE_NOT_FOUND：业务对象、图片不存在或当前用户无访问资格|[ErrorResponse](#schemaerrorresponse)|
|503|[Service Unavailable](https://tools.ietf.org/html/rfc7231#section-6.6.4)|STORAGE_UNAVAILABLE：存储服务暂时不可用|[ErrorResponse](#schemaerrorresponse)|
